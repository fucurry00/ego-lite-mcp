# 常に許可にするのは中身が固定された読み取り専用ツールだけにする

`ego_run_script` は任意の JavaScript を実行でき、書き込み操作も行える。
これがコネクタ設定で「常に許可」になっていたため、承認画面でスクリプトを読むという `docs/design.md` の安全策は、有人実行でも無人実行でも働いていなかった（2026-10-27 に利用者の設定画面で確認）。
そこで、決まった URL を決まった手順で読むだけの読み取り専用ツールを別に立てて、こちらを「常に許可」にし、`ego_run_script` は「その都度確認」に戻す。
安全かどうかの判定を Claude の判断から外し、ツールのコードと許可設定に移すためである。

## 帰結

- 書き込み操作が必要になるたびに `ego_run_script` の確認が入り、タスクを最後まで任せる有人実行でも作業が止まる。これは意図した結果である。
- 無人実行（スケジュールタスク）は、読み取り専用ツールだけで完結するように作る。`ego_run_script` を呼ぶと承認待ちになり、実行されない。
- 読み取り専用ツールが完結するには、たどり着いたページの内容まで返す必要がある。状態だけを返すと、読み取りのために `ego_run_script` を常に許可へ戻すことになり、分けた意味がなくなる。
